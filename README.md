## Database Management System in Java

---

### Project Overvies
This project is a Java-based coursework designed to simulate fundamental database management system functionalities. 
 
It covers table management, data manipulation, and transaction simulation to enhance understanding of database concepts and implementation.

---

### Features
- Create and manage database tables (e.g., add, delete, alter table structures)
- Insert, delete, and update records
- Support simple query operations
- Simulate transaction processes and basic data consistency handling

---

### Technical Details
- Developed using Java, applying Object-Oriented Programming (OOP) principles.
- File-based storage is used for data persistence.
- Custom data structures (e.g., HashMap, List) are implemented to manage tables and indexes.

---

### Project Structure

    /src
    ├── Main.java          // Entry point
    ├── Database.java      // Database management class
    ├── Table.java         // Table class
    ├── Record.java        // Record class
    ├── Transaction.java   // Transaction simulation class
    └── utils/             // Utility functions

---

### How to Run
1. Navigate to the src directory
2. Compile: javac Main.java
3. Run: java Main
